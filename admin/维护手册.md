# 内部工具库 · 维护手册

放在 `admin\` 里，给维护的人看。普通员工只需要双击外面的启动器——
Windows 是 `启动工具库.bat`，Mac 是 `启动工具库.command`，双击都能开，不用装任何东西。

> Mac 版说明：现在 `runtime\` 里装的是 Windows 的 Python（`python.exe`），Mac 用不上，
> 所以 Mac 会去找系统里的 `python3`（Homebrew / python.org / 系统自带都行）。
> 哪天要给 Mac 也做免安装，把 Mac 版运行时放到 `runtime/bin/python3` 就行，
> 启动脚本会自动优先用它，不用改一行代码。Mac 上服务的行为和 Windows 一样：
> 只监听 127.0.0.1、只在本机用。

位置上：这个库在 `<共享盘>\IT\AI需求场景\内部工具库网页`（网络盘 `\\<文件服务器>\<共享目录>`）。
桌面那份 `项目7内部工具库网页` 从 2026-11-09 起是空的存档，不再当源。

## 一、这套东西由什么组成

| 位置 | 干什么 | 能不能删 |
|---|---|---|
| `启动工具库.bat` / `启动工具库.command` | 唯一入口，双击它（Windows 用 `.bat`，Mac 用 `.command`） | 不能 |
| `runtime\` | 自带的 Python 3.13.18，空电脑靠它跑 | 不能 |
| `admin\` | 网页本体 + 两个脚本 + 本手册 | 不能 |
| `软件工具库\` | 能装到本机的工具，留历史版本 | 里面随你加删 |
| `文档代码库\` | skill / 代码 / 规范，不留历史版本 | 里面随你加删 |

`admin\` 里 **4 个是源代码，别删**：
`build_index.py`（扫柜子、生成清单）、`serve.py`（本机小服务）、
`软件库网站.html`（页面本体）、`更新索引.bat`（手动重建清单）。

**3 个是运行产物，删了会自动重建**：
`清单缓存.json`（上次扫的结果）、`索引缓存.json`（校验码缓存）、
`运行端口.txt`（上次用的端口）。

## 二、日常四种操作

### 1. 加一个新工具
1. 在 `软件工具库\` 下建文件夹，名字 = **工具名+版本号+姓名**，连写不带空格
   （例：`WI一致性检查工具2.0用户`）
2. 放进去两样：最新的 zip + `总说明.md`
3. 回网页点右上角「刷新清单」

### 2. 工具出了新版本
1. 新包装进**同一个文件夹**，文件夹名里的版本号改成新的（重命名文件夹）
2. 旧包留在里面就是「历史 N」；删掉，历史就少一条
3. 这个工具的 `总说明.md` 重新渲染一份（见第四节）
4. 点「刷新清单」

### 3. 往文档代码库加东西
1. 建文件夹，名字 = **工具名+姓名**，这一柜**不写版本号**
2. 文件本体直接放进去，几层子文件夹都行
3. 一份 `总说明.md`
4. 点「刷新清单」

### 4. 只改了说明文字
改 `总说明.md`（只能从总表渲染，见第四节），点「刷新清单」。

### 5. 改两个柜子的名字
改 `config.json` 里的 `"dirs"`（`lib` / `doc`），两个柜文件夹跟着改名，
代码不用动。三个目录名只在 `build_index.py` 的 `DIRS` 里写一次。

## 三、怎么打开、怎么刷

- **打开**：双击 `启动工具库.bat`。黑窗口别关，关了工具库就退出。
  现在的顺序是**先开网页、后起服务**：网页一两秒就出来（清单上次扫好的，存在页面里），
  Python 在网络盘上要爬十秒左右，起来以后网页自己跳到服务版，
  「复制 / 打开文件夹」跟着就齐了。这十秒里网页已经能看、能搜、能下载。
- **刷新清单**：网页右上角那个按钮，会真的重新扫一遍柜子（约 3 秒，网络盘上慢一点）。
- **纯网页模式**：电脑上完全没有 Python 时，bat 会直接打开页面，能看能搜能下载；
  「复制」和「打开文件夹」会降级成「复制文件路径」。
  用 bat 起的，这个状态只是开头十来秒的过渡，不是坏了。

## 四、`总说明.md` 从哪来（**不许手写**）

一句话：**从《IT工程部_项目总表》渲染，手改的下次一渲染就没了。**

```
python <工程统一基线skill>\scripts\sync_manual.py ^
       --base <归档库根> --xlsx <IT工程部_项目总表.xlsx> --write
```

- 它会在归档库每个「项目N…」文件夹里写/更新 `总说明.md`（六段结构）
- 再把对应那份**原样拷**进柜子文件夹，同名覆盖
- 只想渲一个项目：用 `--base` 指到一个只放了那一个「项目N」文件夹的目录
- 老的 `说明.txt` 代码还认（第一行当简介），但新放的一律用 `总说明.md`

## 五、出问题怎么查

1. **先看黑窗口最后几行**，出错会打在 `[!]` 或 `[..]` 开头那行
2. 网页右上角有红色提示 → 那是扫描没成功，清单还是上一次的
3. 清单跟柜子对不上 → 删掉 `清单缓存.json` 和 `索引缓存.json`，点「刷新清单」
4. 提示端口被占 → 删掉 `运行端口.txt` 再双击 bat
5. 卡住不动 → 任务管理器结束 `python.exe`，重新双击 bat

## 六、换版本时到底替换哪几个

**只替换 `admin\` 整个文件夹 + `启动工具库.bat`。`runtime\` 和两个柜子不要动。**

- 2026-11-09 起，`serve.py` 扫完会**顺手把清单写回网页里的数据区**，
  所以替换 admin 之后不用再单独跑「更新索引.bat」，打开一次页面就自动补上。
- 如果哪天只在纯网页模式用（不跑 bat），那才需要双击一次 `admin\更新索引.bat`。

**关于启动慢**（2026-11-09 实测）：`runtime\` 放在网络盘上，Python 从起到
`/__ping` 能应答要 **10.3 秒**；同一份代码放本地盘只要 **1.2 秒**。

慢在哪：Python 启动要打开几百个 `.py` / `.pyc` 小文件，每个文件跨网络一次往返。
单看更细的数字：`python.exe -c "pass"` 在 P 盘就要 **6.8~8.4 秒**，
把服务要用的模块 import 完要 **10.6~10.8 秒**（三次取中位）。同一批文件本地盘 0.23 秒。
不是代码的问题，也不是杀毒软件的问题，就是「网络盘读大量小文件」本身贵。

**所以启动顺序改成了「先开网页、后起服务」**（2026-11-09 晚）：
`启动工具库.bat` 先 `start` 把 `admin\软件库网站.html` 叫起来 —— 清单是上次扫好、
烤在页面里的，一两秒就能看能搜能下载；Python 同时在后台慢慢起，
网页每 400 毫秒探一次 `/__ping`，探到了整页跳到 `http://127.0.0.1:端口/`，
「复制 / 打开文件夹」这时才可用。弹窗开着的时候不跳，怕把人家正在看的刷掉。

要再快只有两条路：把 `runtime\` 放本机（首次要从网络盘拷 40MB / 776 个文件，
约 36 秒，之后 1.2 秒），或者整个库放本地盘。目前按决定放 P 盘，用上面的办法把等待藏起来。
（2026-11-09 曾误报「28 秒」，那个数是测试环境里 `PYTHONPATH` 注入了额外模块造成的，已纠正。）
